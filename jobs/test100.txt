Nexora Technologies — Senior Backend Software Engineer, Cloud Platforms
About the Role

We are seeking a Senior Backend Software Engineer to design, develop, and maintain scalable enterprise applications, cloud-native backend services, and distributed data processing systems. You will build secure REST APIs, optimize high-performance backend solutions, modernize legacy applications, and support cloud deployments using Azure, AWS, Docker, and Kubernetes.

The ideal candidate has strong experience with C#, ASP.NET Core, SQL Server, REST APIs, cloud platforms, CI/CD pipelines, and backend system optimization.

Build and optimize enterprise data pipelines for validating, transforming, aggregating, and publishing large-scale datasets.

Improve application performance through:

Collaborate with engineering teams on system design, code reviews, and software delivery.
